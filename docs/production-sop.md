## 一、開新作品

1. 建 `output/<作品名>/`（作品名用中文標題），放一份 `製作紀錄.md`，開頭就有三個區塊：**使用者的決定**、**進度表**、**定稿清單**（檔名＋規格＋路徑）。
2. 照 `畫風索引.md` 挑 3–5 個畫風給使用者選；參考了 awesome-opus5-5-videos 的哪一則提示詞，在製作紀錄寫出處連結。
3. 先出計畫或分鏡給使用者看，再用真正的繪圖程式做三張定格（或一個 10–15 秒試片）確認風格，才做全片。
4. 原始專案放 `work/`；逐格 PNG、配樂 wav 等中間檔放本機暫存資料夾，成品也先寫本機暫存，算完再搬進 `work/`。
5. 使用者確認定案後，成品移到作品資料夾最上層、改名 `<作品名>.mp4`（`_社群版.mp4`、`_手機版.mp4`），舊版移到 `舊版/`，製作紀錄記定稿路徑。
6. 要發布時照 `media-music-video` SOP 第四節清 metadata 並雙重驗證，再照發布資訊範本寫 `發布資訊.md`。

## 二、跨作品已定案的決策

只記結論，理由在 Obsidian（`media-code-video/專案工作流程.md`）。

### 無頭 Edge 算圖（2026-11-06 定案，〈一滴墨〉）

- **程序數要先量再定**：`media-music-video` SOP 的「32 GB 最多 6 個」只適用單層畫面。多層大畫布的片（〈一滴墨〉每個程序 1–2 GB），32 GB 的電腦最多開 2 個。新作品先開 1 個程序，量它的記憶體再決定。
- **關瀏覽器不能只 kill 啟動程序**：Edge 的啟動程序會把真正的瀏覽器分出去後自己結束，照它的 PID 關整棵樹會留下孤兒程序。
  正確做法：先送 CDP 的 `Browser.close`；腳本結束或出錯時，再依「這次專用的設定檔資料夾名稱」找出所有相關的 `msedge.exe` 補殺。
- **每次算完都確認沒有殘留的 `msedge.exe --headless`**。
- 這台的 Edge 不把除錯網址印到 stderr，要從設定檔資料夾的 `DevToolsActivePort` 讀連接埠；無頭 Edge 要在沙箱外執行。
- **補殺只關自己的程序**：依這次的設定檔資料夾名稱找，不要一次關掉所有 `msedge.exe --headless`。同一台電腦可能有別的 session 正在算圖（2026-11-06，〈城市生長〉）。
- **WebGL（Three.js）的片會用到 GPU**：啟動參數加 `--ignore-gpu-blocklist --enable-unsafe-swiftshader`，開頁後印出 `WEBGL_debug_renderer_info` 確認不是軟體算圖。
  〈城市生長〉每格 0.2–0.5 秒，1 個程序（含子程序）約 1.3 GB，1050 格約 3–5 分鐘，1 個程序就夠。
- **頁面錯誤要立刻回報**：`film.html` 先掛 `error`／`unhandledrejection` 收進 `window.ERR`，`render.mjs` 等待就緒時一併檢查。否則模組載入失敗只會空等到逾時。

### 無限縮放與套疊轉場（2026-11-06 定案，〈一滴墨〉）

- **鏡頭用一條「縮放深度」曲線**（ln 倍數，單調三次內插，不會超調）。
  - 第 k+1 層整張畫縮小 F 倍嵌在第 k 層的某一點，各層的畫面座標都從同一個鏡頭推算。
  - 每段的鏡頭平移用兩端速度為零的緩動，換層時才不會頓一下。
- **各層只存墨量（透明度），合到畫面上再一次壓印紙紋**：紙紋固定在畫面上，不會跟著放大變粗。
- **套疊的層只要有一部分看得到，就整組一起畫**。不要用深度門檻分開開關，否則同一個物件（例如一枝筆跨兩層）會被切成兩半、先後出現。
- **穿過入口（窗、門）要算「蓋滿畫面的深度」**：ln(max(畫面寬／入口寬, 畫面高／入口高))＋該層基準深度，再留餘量。
  - 那段深度內鏡頭不平移，內層的套疊點放在內層正中，穿過時才不會露出入口邊框。
  - 改入口大小就要重算。
- **層在淡入時比畫面小**：該層的墨在畫框邊緣 6–10% 內淡掉，否則看得到直線邊。
- **換層不要整張一起淡入淡出**（使用者評「生硬」）。改用雜訊遮罩一塊塊散去、浮出（遮罩跟著層一起放大），兩層交疊的範圍要夠長；入口內的內容跟著外層一起浮現。
- **前景物件擋住後面的線**：在前景物件的位置，把後面那些筆留白（遮罩只作用在後面那些筆上，不是擦墨）。不能讓後面的線穿過前景。

### 程式 3D 場景（2026-11-06 定案，〈城市生長〉）

- **three.js 鎖版本放進作品的 `work/vendor/three/`**：只放 `build/three.module.js`、用到的 `examples/jsm/` 子資料夾（`postprocessing`、`shaders`、`math`）和 `LICENSE`，約 2 MB，用 importmap 載入。
  不要在雲端硬碟裡 `npm install`（`node_modules` 上千檔）；要裝就裝在暫存資料夾再複製。
- **物件前後關係交給深度緩衝**：真 3D 的遮擋自動正確，不會有「後面的線穿過前面的物件」。Canvas 2D 才需要自己排畫的順序或留白（見上一小節）。
- **自己組的幾何，三角形一律逆時針朝外**：反了會從外面看到內側；陰影偏移也跟著反向，表面出現斜紋。新幾何先放大檢查一次。
- **逐格只依時間 t 算出每個物件的狀態，不留狀態**：才能平行算圖、任意抽格。大量同類物件（遠景街區、窗燈）用 `InstancedMesh` 合併成幾批，每格只更新矩陣。
- **正交鏡頭**：縮放（畫面高）用 ln 內插，拉遠拉近的速度感才一致；霧的起訖距離依畫面高換算（畫面高 × cot(仰角) × 係數），地平線才一直留在上方。
- **直式 9:16 要放下整座城**：城的長邊順著畫面垂直方向（方位角接近 90°），仰角 40° 以上，寬度剛好放得下，上方留天空。
- **前段要細節、結尾要規模**：細節版維持原大小，讓每塊落地看得清楚；結尾拉遠時，外圍改用低細節的蔓延（合併繪製、不逐棟發音）給規模感。
  蔓延最外圈不要整齊的方格（沒有路面、縮小錯開、部分留空），否則邊界像階梯。
- **夕陽下的草地會變橄欖色**：後製調色太輕，直接把地面材質的顏色往灰藍綠內插；天亮再轉回來。

### 生長動畫對拍（2026-11-06 定案，〈城市生長〉）

- **每個生長的關鍵時間都對齊十六分音符格**：落下的「落地」、冒出的「出現」、翻起的「開始」。疊樓層可以用三十二分音符。
  預備動作（牆先升、屋頂再落）提前**整整一個**八分音符，不要寫 0.3 秒這種近似值；那會比拍子早一點點，觀眾聽得出來沒踩到拍。
- **所有寫死的秒數都要經過對格函式**（例如 `q(t)`），包括行道樹、鋪面、地基、路燈、車、開場的木樁。
- **用程式掃描，不靠眼睛**：`render.mjs --audit` 匯出畫面每個生長事件的關鍵時間，`tools/beatcheck.mjs` 檢查畫面事件與配樂提示點都在格上（誤差 ≤ 1 毫秒）。改了時間就重跑。
- **看得見的動作都要有聲音**，但同一格十六分音符只留一個音，其他只留很輕的動作聲，才不會變成噪音。
- **加速靠密度不靠節拍**：節拍不變，事件從二分、四分、八分到十六分音符格越排越密。

### 循環短片（2026-11-06 定案，〈一滴墨〉）

- **最後一格與第一格必須是連續的兩格**：結尾的動作用 Hermite 曲線直接接到下一輪開頭的狀態。用 ffmpeg 抽第 0 格與最後一格並排比對。
- **聲音也要接得上**：環境聲用頻域塑形的雜訊（本身是週期性的），殘響用循環卷積；循環點前後各留一段無聲，接縫的第一個聲音是全片最重要的那一聲。
- **片長取整數小節**（〈城市生長〉35 秒＝14 小節），節拍才接得上。
- **結尾換地點接回開頭**（〈城市生長〉）：最後一格的取景、天色、光照、霧都與第 0 格相同，只把看的點換到一塊同材質、同高度的地。
  - 中途改過的值（夜色、地面顏色）在最後一格要回到第 0 格的值。
  - 用逐像素比對驗證：最後一格與第 0 格平均差 < 0.1（滿分 255）。
- **推近遠處目標時，先把目標帶到畫面中央、再推近**。位置與縮放同時內插的話，目標會先滑出畫面再回來。

### 配樂對畫面（2026-11-06 定案，〈一滴墨〉）

- **動作聲的時間點從畫面程式匯出**（`render.mjs --cues`），配樂腳本讀提示點，不手抄秒數。
- **改了鏡頭或節奏，就重新匯出提示點、重新合成配樂。**
- 響度：numpy 混音正規化後，用 ffmpeg `volume`＋`alimiter` 拉到約 −14 LUFS，以 `ebur128` 實測（峰值 ≤ −1 dB）。
- 聲音一律由使用者試聽（agent 聽不到），交片時要說明哪些聲音還沒有人聽過。

### 封面取格（2026-11-06，〈城市生長〉）

- 用 cover 技能路線 A，從成片取格。挑「上方是天空或霧、主體正在動作」的那一格，例如還懸在半空的樓層。
- 全景格的字會壓到城市後排。字後面的暗角在亮的天空上會壓成灰，調到 90 左右。
- 字型用已安裝的源石黑體 Heavy（OFL）。

### 使用者偏好（2026-11-06）

- 節奏偏快：靜止段約 2 秒內，〈一滴墨〉從 72 BPM、40 秒改成 80 BPM、36 秒後才定案。
- 水墨畫裡大面積的焦墨塊會被看成實體（門、簾）。窗內這類「空間」用中淡墨，讓裡面的東西隱約看得到。
- 物件比例要合理：窗要比門小、下緣離地，高:寬約 5:7。
- 喜歡可以循環播放的作品：〈一滴墨〉〈城市生長〉都改成頭尾相接。結尾的新目標要離主體夠遠，才看得出是「下一個」（〈城市生長〉的新空地往外移了兩次）。
- 生長、落地要踩在拍子上，差一點點也會被指出。
